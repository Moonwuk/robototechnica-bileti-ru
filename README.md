# Электротехника и робототехника — билеты

Русский тренажёр для подготовки с помощью вопросов, объяснений и повторения ошибок.

- **360 вопросов** по 12 темам: электрические цепи, измерения, электроника, микроконтроллеры, датчики, приводы, регулирование, кинематика, ПЛК, ROS 2 и диагностика.
- **24 цепочки по 5 вопросов**: короткий словарь, подсказки и самопроверка ответа на вопрос собеседования.
- **12 вводных билетов по 10 вопросов** и **12 смешанных билетов по 20 вопросов**.
- Обучение с объяснением после каждого ответа и самопроверка с разбором в конце.
- Практика по теме и сложности, работа над ошибками и повторение изученного.
- Сохранение результатов, порядка вариантов и незавершённого подхода в `localStorage`.
- Адаптивный интерфейс для телефона, планшета и компьютера; без внешних шрифтов, аналитики и библиотек.

## GitHub Pages

В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Workflow `.github/workflows/pages.yml` проверяет банк и учебную логику, собирает статические файлы и публикует сайт после каждого изменения ветки `main`. Для первого запуска выберите **Actions → Check and deploy GitHub Pages → Run workflow**, если настройка Pages была включена уже после загрузки файлов.

Можно также выбрать **Deploy from a branch → main → /(root)**: готовый `index.html` и все ресурсы находятся в корне, сборка для работы сайта не обязательна. В этом случае удалите или отключите workflow `pages.yml`, чтобы не было двух способов публикации.

## Локальный запуск

Нужен Python 3 или любой статический HTTP-сервер:

```sh
python3 -m http.server 4173
```

Откройте `http://localhost:4173`. Открытие `index.html` через `file://` не подходит, поскольку браузер блокирует загрузку JSON-файлов.

## Проверки и сборка

Нужен Node.js 20 или новее. Установка npm-пакетов не требуется.

```sh
node scripts/check-bank.mjs
node --test tests/core.test.mjs
node scripts/build.mjs
```

Публикуемые файлы находятся в `dist/`. Ссылки на ресурсы относительные, поэтому сайт работает в подкаталоге репозитория GitHub Pages. Навигация использует URL-фрагменты и не требует серверного маршрутизатора.

## Материалы

В `data/` сохранён исходный подготовленный банк версии **1.1.0** от 2 октября 2026 года:

| Файл | Содержание |
| --- | --- |
| `question_bank.json` | Вопросы, ответы, разбор каждого варианта, темы и источники |
| `interview_paths.json` | Учебные цепочки, словари, примеры ответов и критерии самопроверки |
| `beginner_tickets.json` | Вводные билеты |
| `tickets.json` | Смешанные билеты |
| `study_plan.json` | Рекомендуемый порядок и правила обучения |

Формулировки вопросов авторские. Открытые подборки собеседований использованы для выбора тем; технические ответы сверены с первоисточниками, ссылки доступны в разборе ответа. Это учебный банк, а не официальный экзамен или подтверждение допуска к работам.

В режиме самопроверки результат 18/20 — ориентир для самостоятельной учёбы, а не официальный норматив. Вопросы по безопасности объясняют принципы и не заменяют документацию оборудования и рабочие инструкции.

## Прогресс

Данные хранятся только в браузере пользователя под ключом `robototehnika-bileti-ru:progress:v1`. На другом устройстве будет отдельный прогресс. Очистка данных сайта удаляет результаты. Если сохранение заблокировано, сайт показывает предупреждение и продолжает работать в текущем сеансе.

Подсказка не закрывает повторение: вопрос остаётся в разделе «Ошибки» до самостоятельного правильного ответа. После самостоятельных правильных ответов вопросы предлагаются к повторению через 1, 3, 7 и 14 дней. Ответы самопроверки учитываются только после завершения всего билета; изменение выбранного варианта не создаёт дополнительные попытки.
