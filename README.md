# Электротехника и робототехника — билеты

Русский тренажёр для подготовки с помощью вопросов, объяснений и повторения ошибок.

**[Открыть тренажёр](https://moonwuk.github.io/robototechnica-bileti-ru/)** · **[Расчёты по законам Кирхгофа](https://moonwuk.github.io/robototechnica-bileti-ru/#circuits)**

- **420 вопросов** по 18 темам: электрические цепи, измерения, электроника, микроконтроллеры, датчики, приводы, регулирование, кинематика, ПЛК, ROS 2 и диагностика, математика, координаты и ориентация, манипуляторы, оценка состояния, техническое зрение и планирование движения.
- **24 цепочки по 5 вопросов**: короткий словарь, подсказки и самопроверка ответа на вопрос собеседования.
- **12 вводных билетов по 10 вопросов** и **15 билетов по 20 вопросов**, включая 3 билета инженерной практики.
- **12 расчётных задач** со схемами, вводом уравнений и промежуточных вычислений: узлы, контуры и метод контурных токов.
- Обучение с объяснением после каждого ответа и самопроверка с разбором в конце.
- Практика по теме и сложности, работа над ошибками и повторение изученного.
- Сохранение результатов, порядка вариантов и незавершённого подхода в `localStorage`.
- Адаптивный интерфейс для телефона, планшета и компьютера; без внешних шрифтов, аналитики и библиотек.

## GitHub Pages

В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Workflow `.github/workflows/pages.yml` проверяет банк и учебную логику, собирает статические файлы и публикует сайт после каждого изменения ветки `main`. Для первого запуска выберите **Actions → Check and deploy GitHub Pages → Run workflow**, если настройка Pages была включена уже после загрузки файлов.

Можно также выбрать **Deploy from a branch → main → /(root)**: готовый `index.html` и все ресурсы находятся в корне, сборка для работы сайта не обязательна. В этом случае удалите или отключите workflow `pages.yml`, чтобы не было двух способов публикации.

## Локальный запуск

Нужен Python 3 или любой статический HTTP-сервер:

```sh
python3 -m http.server 4173
```

Откройте `http://localhost:4173`. Открытие `index.html` через `file://` не подходит, поскольку браузер блокирует загрузку JSON-файлов.

## Проверки и сборка

Нужен Node.js 20 или новее. Установка npm-пакетов не требуется.

```sh
node scripts/check-bank.mjs
node --test tests/*.test.mjs
node scripts/build.mjs
```

Публикуемые файлы находятся в `dist/`. Ссылки на ресурсы относительные, поэтому сайт работает в подкаталоге репозитория GitHub Pages. Навигация использует URL-фрагменты и не требует серверного маршрутизатора.

Для обновления уже открывавшегося сайта ссылки на CSS, модули и JSON содержат `?v=1.3.0`. При следующем изменении ресурсов повышайте этот номер согласованно в `index.html`, `privacy.html`, импорте `core.js` и `ASSET_VERSION` в `app.js`, а также в импортах `circuits-ui.js`. Android выбирает локальный ресурс по пути URI, поэтому эти параметры не требуют сетевого доступа.

## Прогресс

Данные хранятся только в браузере пользователя под ключом `robototehnika-bileti-ru:progress:v1`. На другом устройстве будет отдельный прогресс. Очистка данных сайта удаляет результаты. Если сохранение заблокировано, сайт показывает предупреждение и продолжает работать в текущем сеансе.

Подсказка не закрывает повторение: вопрос остаётся в разделе «Ошибки» до самостоятельного правильного ответа. После самостоятельных правильных ответов вопросы предлагаются к повторению через 1, 3, 7 и 14 дней. Ответы самопроверки учитываются только после завершения всего билета; изменение выбранного варианта не создаёт дополнительные попытки.

## Обратная связь

Кнопка «Сообщить об ошибке в вопросе» доступна во время решения и в итоговом разборе. Она прикладывает идентификатор, текст и редакцию вопроса, тему и версию банка. «Предложить улучшение» находится в верхней панели на всех экранах.

Форма создаёт черновик GitHub Issue, который пользователь проверяет и отправляет самостоятельно. Нужен аккаунт GitHub; обращения публичны. Ответы и прогресс не включаются. Черновики остаются только в памяти страницы до перезагрузки. Есть копирование полного текста и ручное выделение при недоступном буфере обмена. Если URL слишком длинный, форма явно предлагает скопировать текст и вставить его на GitHub, не обрезая обращение.

Android открывает GitHub в системном браузере. Кнопка Back сначала закрывает форму и сохраняет текущий вопрос. Новые разрешения или сетевой доступ WebView не требуются.

Все 60 вопросов входят в три отдельных билета по 20 вопросов и в тренировку соответствующих тем. В «Первых шагах» сохранены 24 вводные цепочки; к инженерным темам ведёт отдельный блок.

## Расчёты по законам Кирхгофа

Раздел `#circuits` содержит 12 авторских задач: по четыре на токи в узле, напряжения в контуре и метод двух контурных токов. В каждой есть точная SVG-схема со стрелками и полярностями, поля промежуточных шагов, проверка одного шага или всего решения, полный разбор и необязательный свободный черновик. Ввод сохраняется локально под отдельным ключом `robototehnika-bileti-ru:circuits:v1`; прежний прогресс тестов не меняется. Открытие полного разбора помечает завершённую задачу как решённую с разбором.

Числовые поля принимают арифметику, дроби, десятичную запятую и единицы в конце выражения: `12/(2+4)`, `17/11`, `30 мА`. Без единицы число относится к указанной возле поля величине. В линейных уравнениях все величины вводятся в СИ; поддержаны `i`, `i1`, `i2`, скобки, `+ - * /` и один знак равенства. Равносильные уравнения сравниваются по всем коэффициентам, а не только в точке известного решения. Допуск числовой проверки — 0,1%, для нуля — 1e-9.

Проверка выделяет обратный знак, ошибку единиц в 1000 раз и числовой результат, согласующийся с неверными предыдущими данными. Это детерминированный разбор заданных шагов, не оценка произвольного текста: свободные заметки не проверяются. При редактировании шага последующие отметки проверки снимаются.

Парсер не использует `eval`, `Function` или выполнение пользовательского кода. Ограничены длина (160 символов), число токенов (100), вложенность (20) и величина промежуточных чисел (1e12); отклоняются нелинейные выражения и деление на ноль. Пользовательские значения экранируются при вставке в HTML, сообщения проверки выводятся через `textContent`. Никакие вычисления и черновики не отправляются на сервер.

Теоретическая опора: [OpenStax, §10.3](https://openstax.org/books/university-physics-volume-2/pages/10-3-kirchhoffs-rules) и [MIT 6.002, лекция 2](https://ocw.mit.edu/courses/6-002-circuits-and-electronics-spring-2007/resources/6002_l2/). Условия, числовые примеры, решения и схемы авторские. Тесты дополнительно сверяют результаты независимым методом узлового потенциала и балансом мощности.

Новые модули включены в сборку Pages, упаковку APK и список разрешённых локальных ресурсов Android. Для уже установленного APK нужна новая сборка приложения; обновление сайта не меняет старый APK.
