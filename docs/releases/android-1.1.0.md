## Перед передачей APK

1. Дождаться успешных проверок Android и сайта для релизного коммита.
2. Подписать APK первоначальным release-ключом; не заменять его новым или debug-ключом.
3. Выполнить `apksigner verify --verbose --print-certs` для старого и нового APK и сравнить SHA-256 сертификатов.
4. Проверить package, versionCode, minSdk, targetSdk и отсутствие debuggable через инструменты SDK. versionCode нового APK должен быть больше опубликованного.
5. Проверить `zipalign`, состав assets и отсутствие новых разрешений. Сохранить SHA-256 итогового APK.
6. Установить поверх версии из RuStore, не удаляя приложение. Проверить прежний прогресс, незавершённый билет, расчётные задачи, режим без интернета и кнопку «Назад».

Совпадение сертификата и проверки в браузере не заменяют установку на Android. Результаты фактически выполненных проверок прилагаются к передаваемому APK отдельно.

## Публикация

В существующей карточке RuStore выбрать «Загрузить версию», загрузить подписанный `robotics-tickets-1.1.0.apk`, заполнить «Что нового», проверить параметры и отправить на модерацию. Не создавать вторую карточку приложения и не загружать файлы приватного ключа вместо APK.

Сборка и этот PR не отправляют приложение в RuStore автоматически.
